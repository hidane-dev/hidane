# Adopters

Organizations and projects that use hidane, listed by themselves. If yours does, adding it helps
others judge whether hidane fits theirs, and helps the project show that it is used.

## Adding yourself

Open a pull request that adds one row to the table below. Please:

- open it as someone who can speak for the organization or project (a maintainer, an employee
  allowed to say so);
- give public information only: the organization, optionally the project, one short sentence on
  how it uses hidane (for example "runs its Admin SDK test suite in CI against hidane"), the month
  it started (`YYYY-MM`) and an `https` link to the organization's or project's public page;
- no logos, and no claim about the organization beyond how it uses hidane.

A row is removed when the organization asks, by pull request or by an issue, without questions.
This list is the only record of who uses hidane that the project keeps.

hidane.dev may show the list: `python3 tools/parity/site_data.py` turns the table into
`website/public/data/adopters.json`, and CI checks that it is in step and that each row has an
organization, a use, a month and an `https` link.
