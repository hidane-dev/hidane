# hidane (火種, *the seed of fire*) — a Firestore emulator without Java.

hidane (pronounced *hi-da-ne*) aims to be a drop-in replacement for the official
Cloud Firestore emulator: a single Rust binary that starts in milliseconds, speaks
the same gRPC / REST / WebChannel protocols, runs under `firebase-tools`, and is
tested for parity against the official emulator as the oracle.
