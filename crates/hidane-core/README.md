# hidane-core

The Firestore data model of [hidane](https://github.com/hidane-dev/hidane), a Firestore emulator
without Java: value ordering, an order-preserving key encoding, the in-memory store, field
transforms and the official emulator's export format.

This crate exists to build the `hidane` binary. Its API follows hidane's needs and may change in
any release; depend on it at your own risk.
