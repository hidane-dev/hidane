# Project assets

The official places where hidane is developed, published and announced. A package, image, site or
account that uses the name and is not listed here does not belong to the project. If you find one
that looks like it is trying to pass for hidane, please open an issue, or report it privately as
[SECURITY.md](../SECURITY.md) describes when it looks malicious.

## Repositories

All under the GitHub organization [`hidane-dev`](https://github.com/hidane-dev).

| Repository | What it holds |
|---|---|
| [hidane-dev/hidane](https://github.com/hidane-dev/hidane) | The source, issues, [Discussions](https://github.com/hidane-dev/hidane/discussions) and [releases](https://github.com/hidane-dev/hidane/releases) |
| [hidane-dev/setup-hidane](https://github.com/hidane-dev/setup-hidane) | The GitHub Action `hidane-dev/setup-hidane` |
| [hidane-dev/homebrew-tap](https://github.com/hidane-dev/homebrew-tap) | The Homebrew formula |
| [hidane-dev/benchmark-results](https://github.com/hidane-dev/benchmark-results) | The canonical benchmark's results, every night and every release (CC BY 4.0) |
| [hidane-dev/.github](https://github.com/hidane-dev/.github) | The organization's profile |

## Packages

| Channel | Name |
|---|---|
| GitHub Releases | `hidane-<version>-<target>` archives, `sha256sums.txt` and build provenance attestations ([releasing.md](releasing.md#assets)) |
| crates.io | [`hidane`](https://crates.io/crates/hidane), and the libraries it is built from: `hidane-core`, `hidane-proto`, `hidane-rules` |
| npm | [`hidane`](https://www.npmjs.com/package/hidane), and the binaries it installs under the `@hidane-dev` scope: `@hidane-dev/darwin-arm64`, `@hidane-dev/darwin-x64`, `@hidane-dev/linux-arm64`, `@hidane-dev/linux-x64`, `@hidane-dev/win32-x64`. The npm scope `@hidane` is not the project's |
| pub.dev | [`hidane`](https://pub.dev/packages/hidane), from the verified publisher `hidane.dev` |
| Container image | [`ghcr.io/hidane-dev/hidane`](https://github.com/hidane-dev/hidane/pkgs/container/hidane) |
| Homebrew | `hidane-dev/tap/hidane` |
| GitHub Actions | `hidane-dev/setup-hidane` |
