# hidane.dev

Static site for https://hidane.dev, served from Cloudflare Workers (static assets plus a tiny Worker
for the `www` redirect and `install.sh`). Tooling runs on [bun](https://bun.sh).

```sh
bun install          # installs wrangler
bun run dev          # http://localhost:8787
bun run check        # wrangler deploy --dry-run
bunx wrangler login  # once per machine
bun run deploy       # creates the custom-domain DNS records on first deploy
```

- `public/` — the site. `index.html` (English), `ja/index.html`, `404.html`, `install.sh` (placeholder that exits 1 until the first release), `og.png`, `favicon.svg`, `_headers`, `robots.txt` and `sitemap.xml` (both pages, with their `hreflang` alternates as the pages declare them; add a page there when one is added). The Parity sections' table (between `<!-- parity:start -->` and `<!-- parity:end -->`) and `badge/parity.json` (the README's shields.io badge) are generated by `tools/parity/table.py`.
- `public/data/` — public data for pages the site may add (`/compatibility`, `/benchmarks`, `/adopters`), served as `https://hidane.dev/data/<name>.json` and generated by `tools/parity/site_data.py` (CI checks it): `compatibility.json` (the hidane × firebase-tools × official emulator matrix, each client's status, version, what was exercised and its evidence, parity counts, differences by kind; from `docs/compatibility.json`, `docs/sdk-certification.json` and `docs/parity-exceptions.json`), `benchmarks.json` (where the canonical benchmark results are: `hidane-dev/benchmark-results` and its `index.json`, their license, and the results the pages cite) and `adopters.json` (the table of `ADOPTERS.md`). No page reads them yet. A page that fetches the benchmark index from `raw.githubusercontent.com` needs that host in `connect-src` of `_headers`, or a copy served from the site.
- `src/index.js` — the Worker.
- `wrangler.jsonc` — custom domains `hidane.dev` and `www.hidane.dev`.

Design source: the hidane.dev canvas (dark "sumi + ember", light "kinari + charcoal", IBM Plex Sans JP / IBM Plex Mono).
